<p class="text-black text-base leading-normal md:text-xl lg:text-2xl  xl:text-2xl font-normal pb-10 w-full max-w-[46rem] w-full company-blurb">
Traces captures coding agent sessions and makes them shareable, searchable, and linked to the git commits they produced, helping teams learn from their work with AI.
</p>

<div class="border-t border-b border-gray-200 py-10">
<p class="text-pink-500 text-base leading-normal md:text-xl lg:text-xl md:leading-snug font-light">
We helped make Traces a more reliable platform for capturing agent work and turning it into knowledge teams and their agents can build on.
</p>
</div>

<div class="md:pt-0 md:pb-0 py-10">
<p class="md:pt-12 text-black text-base leading-normal md:text-xl lg:text-xl md:leading-snug font-light pb-4 md:pb-7">
We drove the redesign of trace sharing, making it 5–15× faster while sending less data in our internal benchmarks. We also made sharing more resilient to failures, keeping it reliable as sessions grew.
</p>

<p class="text-black text-base leading-normal md:text-xl lg:text-xl md:leading-snug font-light pb-4 md:pb-7">
We helped strengthen the foundations of session capture with stable identifiers for traces, messages, and parts, more reliable git and agent hooks, and more complete capture of agent sessions across adapters. We also helped build bulk uploads of local traces to make onboarding easier for new users.
</p>

<p class="text-black text-base leading-normal md:text-xl lg:text-xl md:leading-snug font-light pb-4 md:pb-7">
We helped build <a href="https://traces.com/surfaces" class="underline hover:text-pink-500">Surfaces</a>, letting users explore their agent sessions from different perspectives, including file changes, security reviews, token usage, and skills. We designed Surfaces so teams could create and publish their own views.
</p>

<p class="text-black text-base leading-normal md:text-xl lg:text-xl md:leading-snug font-light">
We built <a href="https://traces.com/blog/traces-mcp" class="underline hover:text-pink-500">Traces MCP</a> to let agents search and retrieve domain context from a team's past sessions.
</p>
</div>
